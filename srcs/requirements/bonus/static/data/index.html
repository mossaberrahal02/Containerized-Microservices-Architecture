Inception

Inception is a system administration project that involves setting up a small infrastructure composed of different services using Docker. The project consists of creating a multi-container application with NGINX, WordPress, and MariaDB, each running in its own container. All services are orchestrated using Docker Compose and run in a custom Docker network. The infrastructure follows security best practices, including the use of environment variables for sensitive data and volumes for data persistence.
